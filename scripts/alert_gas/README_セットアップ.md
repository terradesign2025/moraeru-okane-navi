# 無料アラート登録 → スプレッドシート記録＋メール通知 セットアップ手順

所要時間: 約5分。完了すると、アプリの「無料アラート登録」で入力された
お名前・メールアドレス等がスプレッドシートに自動記録され、
terradesignik@gmail.com に即時メール通知が届きます。

## 手順

1. **スプレッドシートを用意**
   - Googleドライブで新規スプレッドシートを作成（名前例: `もらえるお金ナビ_アラート登録者`）
   - ※ KOMEKO NOTE・休日ドクターナビと同じ共用シートに追加してもOK（シートは自動作成されます）

2. **GASを開く**
   - スプレッドシートのメニュー → 拡張機能 → Apps Script

3. **コードを貼り付け**
   - `Code.gs` の中身を全部削除し、このフォルダの `Code.gs` を丸ごと貼り付けて保存

4. **一度テスト実行（権限承認）**
   - エディタ上部で関数 `testAppend` を選んで「実行」
   - 権限承認ダイアログが出たら許可（スプレッドシート＋メール送信）
   - シート「アラート登録者」にテスト行が入り、通知メールが届けば成功

5. **ウェブアプリとしてデプロイ**
   - 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - デプロイ → 表示された **ウェブアプリURL** をコピー

6. **アプリに反映**
   - `src/App.jsx` の `ALERT_WEBHOOK_URL = ''` にコピーしたURLを貼る
   - `npm run build` → デプロイ（Claudeに「アラートURLを設定して」と依頼でもOK）

## 補足

- URLが空('')の間は送信されず、従来どおり完了画面のみ表示されます（サイトは壊れません）
- GASウェブアプリURLは公開されても第三者が悪用しにくい構造ですが、
  スパム行が増えた場合はデプロイを更新してURLを変更してください
- コードを修正した場合は「デプロイ」→「デプロイを管理」→ 鉛筆マーク → 新バージョンで更新
